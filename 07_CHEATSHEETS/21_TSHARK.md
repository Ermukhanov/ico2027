# Tshark

## Назначение

Командная строка Wireshark для пакетного анализа.

## Основные команды и примеры

tshark -r CAPTURE -c 20
tshark -r CAPTURE -T fields -e frame.time -e ip.src -e ip.dst -e dns.qry.name
tshark -r CAPTURE -Y "http.request" -V

## Полезные варианты и ключи

-Y: фильтр отображения; -T fields: таблица полей; -e: добавить поле; -w: записать захват.

## Типичные ошибки

Имена полей должны существовать для протокола; не разбирай двоичные данные как текст без проверки.

## Что проверить в CTF

Сверь агрегаты и фильтры, затем открой нужный поток в Wireshark.
