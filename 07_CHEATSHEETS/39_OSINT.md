# OSINT

## Назначение

Пассивно собирать и связывать публичные сведения в рамках учебного задания, не взаимодействуя с чужими системами сверх разрешённой области.

## Основные команды и примеры

    whois example.org
    dig example.org A +short
    dig example.org TXT
    curl -I https://example.org
    git -C REPO log --all --oneline
    git -C REPO grep -n -i 'TODO\|secret\|flag'
    exiftool IMAGE

## Полезные варианты и ключи

- DNS: `A`, `AAAA`, `MX`, `TXT`, `NS`; сохраняй resolver, время и точный ответ.
- Git: проверь локальные ветки, историю и удалённые ссылки; не подключайся к удалённому origin в офлайн-поездке.
- HTTP HEAD (`curl -I`) показывает метаданные ответа; не делает скрытый контент публичным автоматически.
- Поисковые операторы сайта используй только в публичной поисковой системе; сохраняй запрос, URL и дату.

## Типичные ошибки

Публичная доступность не означает разрешение на вход/сканирование. DNS-данные меняются и могут быть кэшированы; зафиксируй время наблюдения. Не собирай личные данные вне явно заданной цели и правил соревнования.

## Что проверить в CTF

Ищи домены, email-адреса, имена хостов, DNS TXT, публичные Git-коммиты и метаданные вложений, если условие прямо направляет к этому источнику. Сопоставляй минимум два независимых признака.
