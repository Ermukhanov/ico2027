# File Formats

## Назначение

Определение контейнера/формата и проверка структуры файла.

## Основные команды и примеры

file FILE; xxd -g 1 -l 64 FILE
xxd -s -64 FILE
7z l ARCHIVE; unzip -l ARCHIVE

## Полезные варианты и ключи

Сравни magic bytes, длину, таблицы и checksum; архив листай до извлечения.

## Типичные ошибки

Расширение можно переименовать; вложенный архив или полиглот меняет интерпретацию.

## Что проверить в CTF

Сопоставь фактический формат с ожидаемым, проверь хвост и извлекай в отдельную папку.

## Рабочая заметка

Скопируй команду и её вывод в заметки вместе с путём к входному файлу. Перед выводом проверь, что результат повторяется на том же входе и не зависит от случайного состояния оболочки.
