# Bash

## Назначение

Связывание команд, переменные и безопасная работа в оболочке.

## Основные команды и примеры

set -euo pipefail
file -- "$f"
find . -type f -print0 | xargs -0 -n1 file
printf '%s\n' "$PATH"

## Полезные варианты и ключи

-e: завершаться при ошибке; -u: ловить неопределённые переменные; -o pipefail: видеть ошибку в конвейере.

## Типичные ошибки

Кавычь переменные с путями и пробелами; не вставляй недоверенный текст в eval.

## Что проверить в CTF

Для пакетной сортировки файлов используй нулевой разделитель -print0/-0.

## Рабочая заметка

Скопируй команду и её вывод в заметки вместе с путём к входному файлу. Перед выводом проверь, что результат повторяется на том же входе и не зависит от случайного состояния оболочки.
