# Quick Reference

## Назначение

Короткая команда-подсказка; для деталей открой профильную страницу.

## Основные команды и примеры

Linux: pwd; ls -lah; find . -type f
Файл: file F; sha256sum F; xxd -l 64 F
ELF: checksec F; readelf -h F; gdb -q F
PCAP: tshark -r F -q -z io,phs; tshark -r F -Y dns
Web: curl -i URL; ffuf -u URL/FUZZ -w wordlists/common.txt

## Полезные варианты и ключи

-h/--help: справка; -r: recursive/read; -n/-i: строки/без регистра; сохраняй вывод в файл.

## Типичные ошибки

Подставляй реальные локальные пути и только разрешённые URL; не считай инструмент установленным без command -v.

## Что проверить в CTF

Определи направление задачи и открой соответствующую шпаргалку/тему руководства.

## Рабочая заметка

Скопируй команду и её вывод в заметки вместе с путём к входному файлу. Перед выводом проверь, что результат повторяется на том же входе и не зависит от случайного состояния оболочки.
