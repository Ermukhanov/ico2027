# Python

## Назначение

Быстрая проверка и обработка данных Python 3.

## Основные команды и примеры

python3 --version
.venv/bin/python -m pip check
.venv/bin/python -c 'from pathlib import Path; print(Path("FILE").stat().st_size)'
.venv/bin/python -m json.tool FILE.json

## Полезные варианты и ключи

-m запускает модуль; venv хранит изолированные библиотеки; pathlib безопаснее склейки путей.

## Типичные ошибки

Системный python3 может не видеть проектные пакеты. Для Scapy/Pwntools используй .venv/bin/python.

## Что проверить в CTF

Перед скриптом уточни кодировку, тип данных и аргументы; пиши маленькие повторяемые преобразования.

## Рабочая заметка

Скопируй команду и её вывод в заметки вместе с путём к входному файлу. Перед выводом проверь, что результат повторяется на том же входе и не зависит от случайного состояния оболочки.
