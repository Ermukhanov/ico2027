# Git

## Назначение

Изучение истории, diff и строк в уже локальном Git-репозитории.

## Основные команды и примеры

git -C REPO status --short
git -C REPO log --oneline -10
git -C REPO grep -n PATTERN
git -C REPO show COMMIT:PATH

## Полезные варианты и ключи

--oneline: компактная история; -S TEXT: найти изменение числа вхождений; diff --stat: обзор изменений.

## Типичные ошибки

Не применяй reset, clean или checkout к неизвестным локальным изменениям. Не путай рабочее дерево с HEAD.

## Что проверить в CTF

Проверь .git, историю решения и случайно оставленные ключи/подсказки.
