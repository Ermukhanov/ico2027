# Gdb

## Назначение

Пошаговая отладка локального ELF.

## Основные команды и примеры

gdb -q ./program
(gdb) set disassembly-flavor intel
(gdb) break main
(gdb) run
(gdb) info registers; x/16gx $rsp; disassemble main

## Полезные варианты и ключи

b: breakpoint; ni/si: шаг через/внутрь инструкций; x/FMT ADDRESS: память; bt: стек вызовов.

## Типичные ошибки

Передавай аргументы через set args; отладчик останавливается по сигналам и это не всегда ошибка программы.

## Что проверить в CTF

Смотри регистры согласно ABI и сравнивай состояние до/после вызова функции.

## Рабочая заметка

Скопируй команду и её вывод в заметки вместе с путём к входному файлу. Перед выводом проверь, что результат повторяется на том же входе и не зависит от случайного состояния оболочки.
