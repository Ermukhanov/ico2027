# Useful One Liners

## Назначение

Повторяемые короткие конвейеры для первичной сортировки.

## Основные команды и примеры

find . -type f -print0 | xargs -0 file
find . -type f -printf '%s %p\n' | sort -n | tail
sha256sum FILE; file FILE; strings -a FILE | head

## Полезные варианты и ключи

Применяй `-print0`/`-0` для пробелов в путях; `tee` сохраняет вывод одновременно.

## Типичные ошибки

Конвейер может скрыть ошибку ранней команды без pipefail; не пускай вывод в команду, меняющую данные.

## Что проверить в CTF

Каждой команде дай один вопрос: тип? самый большой файл? новые строки? хеш?

## Рабочая заметка

Скопируй команду и её вывод в заметки вместе с путём к входному файлу. Перед выводом проверь, что результат повторяется на том же входе и не зависит от случайного состояния оболочки.
