# Regex

## Назначение

Поиск паттернов в логах, исходниках и выводах инструментов.

## Основные команды и примеры

rg -n -i 'flag|token|password' PATH
grep -Eo '[0-9a-f]{32}' FILE
sed -n '10,30p' FILE

## Полезные варианты и ключи

-i: без учёта регистра; -F: буквальный текст; -o: вывод только совпадения; -n: номер строки.

## Типичные ошибки

Regex метасимволы меняют смысл шаблона; экранируй точку и квадратные скобки.

## Что проверить в CTF

Ищи широкими терминами, потом перепроверяй контекст и происхождение совпадения.
