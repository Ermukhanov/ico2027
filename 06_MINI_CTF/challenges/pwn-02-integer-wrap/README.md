# Усечение длины до uint8_t

**Категория:** Pwn / ошибка целочисленного преобразования. **Цель:** найти ввод, который проходит условие проверки после сужения типа.

Осмотри `challenge/chall.c`, затем проверь уже собранный ELF командой `file challenge/chall`. Запусти его локально и исследуй границы вокруг 255. Сервис и сеть не используются. Решатель: `python3 solve/solve.py`.
