# Разбор: path traversal

Обработчик соединяет `www` с пользовательской строкой и читает путь до нормализации/проверки, что итоговый путь остаётся внутри каталога. Значение `../secret.txt` поднимается на уровень каталога задания. Сервер привязан только к loopback. Исправление: нормализовать путь, проверить `resolve().is_relative_to(WEB_ROOT.resolve())` и отказать при выходе за root.
