# Локальный просмотрщик документов

**Категория:** Web / path traversal. Приложение слушает строго `127.0.0.1:8008`; наружу оно не публикуется.

Решатель вызывает функцию обработки запроса напрямую и не требует сокета: `python3 solve/solve.py`. Для интерактивной проверки можно запустить `python3 challenge/app.py` и открыть `http://127.0.0.1:8008/`; сервер слушает только loopback. Сравни публичное чтение `guide.txt` с проверкой нормализации относительного пути; останови сервер Ctrl-C.
