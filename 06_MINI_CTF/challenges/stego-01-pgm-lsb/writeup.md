# Разбор: Младший бит пикселя

## Наблюдения

PGM P2 хранит числовые уровни серого. После четырёх заголовочных значений прочитай младший бит каждого пикселя, собирай по 8 бит в байт и остановись на закрывающей скобке формата.

## Проверка

Из каталога этого задания выполни `python3 solve/solve.py`. Решатель должен вывести полный флаг. Сохраняй исходный артефакт без изменений.
