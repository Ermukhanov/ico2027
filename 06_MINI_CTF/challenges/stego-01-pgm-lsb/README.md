# Младший бит пикселя

**Категория:** Stego  
**Цель:** Извлечь байты из LSB серого PGM без внешних библиотек.

## Файлы

- `challenge/hidden.pgm` — исходный локальный артефакт.
- `solve/solve.py` — проверочный решатель; запускай только после своей попытки.
- `writeup.md` — решение и проверяемые наблюдения.

## Работа

Запусти команды из каталога задания. Внешняя сеть не используется; привилегии администратора не нужны. Сначала сохрани хеш артефакта, затем делай анализ. Не публикуй флаги в общий CTF.
