# Разбор: Однобайтовый XOR

## Наблюдения

Перебери 256 однобайтовых ключей и отфильтруй по формату ICO. Проверь, что вся строка печатная и закрывается фигурной скобкой.

## Проверка

Из каталога этого задания выполни `python3 solve/solve.py`. Решатель должен вывести полный флаг. Сохраняй исходный артефакт без изменений.
