# Справочник по скриптам

Проверены исходники всех файлов в `scripts/`. Запуски оболочек сохранены из интерфейса самих файлов. Большинство оболочек ссылаются на `$HOME/ico2027/scripts`; в этом репозитории путь `/home/zuck/ico2027` совпадает, если используется этот пользовательский каталог. Перед запуском прочитай исходник и используй только свои локальные файлы/разрешённые цели.

## `scripts/README.md`

**Что делает:** Содержит список 60 оболочек-помощников, сгруппированных по направлениям.
**Когда использовать:** Когда нужно выбрать готовый сценарий для знакомого типа задачи.
**Открыть:**

```bash
less scripts/README.md
```

**Аргументы:** `scripts/README.md`
**Вход:** Вход определяется аргументами запуска; открой исходник, если формат неочевиден.
**Выход:** Печатный текстовый отчёт/ответ команды. Точный формат смотри в исходном коде.
**Как понять результат:** результат показывает только то, что именно проверил скрипт. Учитывай фильтры, ограничения и ошибки из исходника.
**Что делать дальше:** Сверь результат с условием, проверь его другим способом и запиши следующий шаг.
**Связанные команды:** смотри используемые программные команды в исходнике файла `scripts/README.md` для проверки деталей.
**Сложность:** средний/продвинутый

## `scripts/vol.py`

**Что делает:** Запускает Volatility 3 из локального checkout через `.venv`, выбирает cache dir внутри проекта и не требует команды `volatility3` в системном PATH.
**Когда использовать:** Когда анализируешь предоставленный memory dump или проверяешь локальную установку Volatility.
**Запуск:**

```bash
scripts/vol.py -h
scripts/vol.py frameworkinfo.FrameworkInfo
scripts/vol.py -f MEMORY windows.info
```

**Аргументы:** Команды и параметры передаются CLI Volatility; доступные плагины зависят от образа и версии.
**Вход:** Для анализа нужен локальный dump; справка и framework info запускаются без образа.
**Выход:** Справка либо результат выбранного плагина; формат зависит от renderer Volatility.
**Как понять результат:** Framework info подтверждает запуск framework, но не результат анализа памяти.
**Типичная ошибка:** Запуск исходника напрямую может писать кэш вне каталога проекта; используй wrapper.
**Связь с ICO-задачами:** Forensics / анализ дампов памяти, если такой артефакт дан.
**Сложность:** средний/продвинутый
