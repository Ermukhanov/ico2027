# ПОЛЕВОЕ РУКОВОДСТВО ICO 2027 — ПОДГОТОВКА БЕЗ ИНТЕРНЕТА

## ТЕКУЩИЕ ПРОБЛЕМЫ

Ошибки APT означают, что WSL сейчас не может обратиться к сети Kali/RubyGems. Ошибки `pip` могут быть вызваны защитой PEP 668 в Kali. Для системных пакетов используй APT, для библиотек Python — виртуальное окружение, для отдельных консольных приложений — pipx. Не используй `sudo pip install` как обычный способ установки.

### Порядок восстановления

1. Windows PowerShell: `wsl --shutdown`
2. Reopen Kali.
3. `getent hosts github.com`
4. `getent hosts pypi.org`
5. `getent hosts rubygems.org`
6. If DNS works: `sudo apt update`
7. Install Python support.
8. Create `~/ico2027/.venv`.
9. Install Python libraries inside the venv.
10. Install Ruby/zsteg only after network works.
11. Download wheelhouse/repos.
12. Make two backups.

`Rev Zero` → декодировать Base64, затем обратить строку.

`Wolf Protocol` → обратить в обратном порядке S-box, LCG/XOR и циклический сдвиг, как описано в локальном writeup.

`Can you hear the flag?` → извлечь звук и изучить спектрограмму, согласно локальному writeup.

`Five Shards` → локальный writeup описывает починку заголовка WAV, проверку EXIF, DNS/Base32 и PNG LSB/zlib, затем объединение подсказок.

`NorthStar` → исследовать запрос входа и обработку данных только на разрешённой задаче.

`Backdoor` → локальный writeup рассматривает WordPress REST/маршрут и артефакты сервера, указанные задачей.

`PixelMart` → восстановление 32-битного LCG, у которого неизвестны младшие 16 бит состояния.

`VIP Club` → локальный writeup описывает уязвимую схему `SHA256(secret||message)`, удлинение хеша и HMAC как безопасную конструкцию.

`Journal Operator` → format string, смещение в стеке и управляемая запись, согласно writeup.

`AEZAKMI` → переполнение стека, смещение, ROP и целевая функция, согласно writeup.
