# Основные инструкции для работы с репозиторием

Прочитай `~/ico2027/docs/ICO2027_FIELD_MANUAL.md`. Сохраняй все пользовательские файлы и оригинальные материалы задач; не удаляй и не перезаписывай доказательства. Не используй `sudo pip`. Для библиотек Python используй виртуальное окружение, для системных пакетов Kali — APT. Если DNS или сеть не работают, останови загрузки и сообщи точную ошибку. Перед разрушительными или очень крупными операциями запроси подтверждение. Используй сетевые и Pwn-инструменты только для разрешённых CTF-целей и лабораторий. Клонируй публичные репозитории из `RESOURCE_URLS.txt`. Собери и проверь скрипты, подготовь локальный wheelhouse, выполни compileall и проверки импортов, создай SHA256-манифесты и резервную копию `99_BACKUP/ico2027-full.tar.gz`. В конце перечисли, что прошло и что завершилось ошибкой. Если на ICO запрещён внешний ИИ, используй Codex только до соревнования.
