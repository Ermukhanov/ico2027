# Практический повтор за один час

Все входные файлы ниже уже есть в проекте. Выполняй команды из корня `/home/zuck/ico2027`; сохраняй вывод и отмечай следующий шаг. Курс не требует сети.

## 00–08 минут — открыть проект и найти материал

```bash
cd /home/zuck/ico2027
pwd
find ico-2027/ico_qualifying_round -maxdepth 2 -type f | sort | head -20
rg -n "Journal Operator|VIP Club|Rev Zero" ico-2027/ico_qualifying_round/ico_ctf_writeup.md
```

**Увидишь:** путь проекта, локальные описания/изображения и совпадения в writeup. **Смысл:** описание и файл задания — разные вещи. **Дальше:** выбери реально существующий файл из списка.

## 08–16 минут — первичная проверка файла

```bash
F=ico-2027/ico_qualifying_round/tasks/sha256_ext.py
file "$F"
stat "$F"
sha256sum "$F"
strings -a "$F" | head -20
```

**Увидишь:** тип, размер, хеш и читаемые строки. **Смысл:** тип определяй по содержимому, хеш позволяет проверить неизменность. **Если файл не найден:** проверь написание через `find`; не подменяй его вымышленным вложением. **Дальше:** прочитай исходник и сформулируй гипотезу.

## 16–24 минуты — кодирование и XOR

```bash
printf 'SUN' | base64
printf 'U1VO' | base64 -d
python3 scripts/base_decode.py --help
python3 scripts/xor_singlebyte.py --help
```

Если у скрипта нет `--help`, открой его начало: `sed -n '1,180p' scripts/xor_singlebyte.py`. **Увидишь:** обратное декодирование даёт `SUN`; интерфейс скрипта виден в исходнике. **Смысл:** кодировка обратима без секрета, XOR требует ключа/гипотезы. **Дальше:** выбери тему 09–15 в `TRAIN_MANUAL.md` и реши одну практику.

## 24–32 минуты — хеши и криптография

```bash
printf 'ICO practice\n' > /tmp/ico-practice.txt
sha256sum /tmp/ico-practice.txt
python3 scripts/hash_report.py --help
python3 scripts/rsa_helpers.py --help
```

Если интерфейс не поддерживает `--help`, прочитай исходник командой `sed -n '1,180p' PATH`. **Увидишь:** хеш фиксированного тестового текста и допустимые аргументы скриптов. **Смысл:** хеш не расшифровывается; RSA требует конкретных параметров. **Дальше:** определи, какая именно величина дана в выбранной задаче.

## 32–40 минут — веб и сеть

```bash
python3 scripts/web_probe.py --help
python3 scripts/pcap_summary.py --help
command -v curl gobuster tshark
```

**Увидишь:** справку, если скрипт её реализует, и пути установленных программ. **Смысл:** активное сканирование допустимо только на выданной цели; в каталоге проекта PCAP может не быть. **Дальше:** для существующего захвата используй `tshark -r CAPTURE -q -z io,phs`, подставив настоящий путь; без захвата повтори фильтры в теме 26.

## 40–48 минут — форензика

```bash
find ico-2027/ico_qualifying_round/tasks -maxdepth 1 -type f -printf '%f\n' | sort
file ico-2027/ico_qualifying_round/tasks/*
python3 scripts/png_chunks.py --help
```

**Увидишь:** реальные изображения и вспомогательные файлы, их распознанные типы. **Смысл:** изображения задач не всегда являются challenge-артефактами. **Дальше:** изучи тему 20–25; обрабатывай только реально имеющееся вложение.

## 48–56 минут — reverse и Pwn

```bash
command -v readelf objdump gdb
find 05_REPOS/ico-tasks -type f \( -name '*.zip' -o -name '*.elf' \) -printf '%p\n'
unzip -l 05_REPOS/ico-tasks/finals/18/2025-ICO-Q18-reverseExe.zip
```

**Увидишь:** доступные архивы и состав одного локального архива. Не запускай неизвестный бинарник. **Смысл:** наличие ZIP не означает, что бинарник уже распакован или проверен. **Дальше:** для разрешённого локального бинарника начни с `file`, `checksec` и `readelf -h`; иначе разбери текст задачи и writeup.

## 56–60 минут — ICO workflow и итог

```bash
sed -n '1,100p' ico-2027/ico_qualifying_round/RULES.md
find 05_REPOS/ico-tasks/finals -type f -name '*.zip' -printf '%p\n'
```

**Увидишь:** правила и четыре имеющихся ZIP ICO 2025. Для ICO 2027 локальны правила, writeup и связанные картинки, но внешние бинарники/медиа отсутствуют. Запиши по одному материалу: тип задачи, локальный путь, первую команду, наблюдение, гипотезу и следующий шаг.

**Курс пройден, если** можешь воспроизводимо объяснить один следующий шаг для каждого выбранного артефакта и отличаешь локально доступные данные от внешних.
