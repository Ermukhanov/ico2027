# Начни здесь: подготовка к ICO 2027 офлайн

Ты начинаешь с нуля? Иди по порядку. Здесь есть руководства, скрипты и описания задач ICO. Некоторые бинарники и медиа ICO 2027 размещены отдельно и не входят в локальную копию. Не считай описание задачи самим файлом задания.

## Первые 15 минут

1. Перейди в репозиторий: `cd /home/zuck/ico2027`.
2. Выполни `pwd && ls -lah docs scripts`.
3. Прочитай этот файл, затем `docs/TRAINING_STATUS.md` и `docs/OFFLINE_STATUS.md`.
4. Пройди темы 00–05 в `docs/TRAIN_MANUAL.md`.
5. Проверь наличие команд в `docs/TOOL_INDEX.md`. Локальные программы проекта появятся после `source scripts/local_tools_env.sh`. Пакеты Python используй после `source .venv/bin/activate`.

## Порядок обучения

1. **Основы:** `TRAIN_MANUAL.md`, темы 00–19: терминал, первичная проверка файлов и криптография.
2. **Форензика и сети:** темы 20–34.
3. **Обратная разработка и Pwn:** темы 35–58.
4. **Особые темы и ICO:** темы 59–67.
5. **План занятий:** `5H_TRAINING_PLAN.md`. Временные блоки, заданные в плане, в сумме составляют 6 часов; имя файла оставлено по запросу.
6. **Срочное повторение:** `1H_CRASH_COURSE.md`.
7. **Повторение команд:** `MEMORIZATION.md`.
8. **Справочники:** `TOOL_INDEX.md` и `SCRIPT_INDEX.md`.
9. **Видео:** `VIDEO_INDEX.md` содержит подобранные материалы с пометкой языка и субтитров. Локальных видеозаписей пока не найдено.

## Связь с задачами ICO

Открой `ico-2027/ico_qualifying_round/ico_ctf_writeup.md`. В нём описаны `Rev Zero`, `Wolf Protocol`, `Can you hear the flag?`, `Five Shards`, `NorthStar`, `Backdoor`, `PixelMart`, `VIP Club`, `Journal Operator` и `AEZAKMI`. Официальные названия сохранены. Writeup говорит, что бинарники и медиа задач 2027 года размещены отдельно; они не гарантированно доступны без Интернета.

В материалах ICO 2025 смотри `05_REPOS/ico-tasks/README.md`, `quals/` и `finals/`. Изучай реальное условие задачи, а не делай выводы только по названию.

## Локальная среда

```bash
cd /home/zuck/ico2027
source scripts/local_tools_env.sh
source .venv/bin/activate
python -m pip check
```

В поезде рассчитывай на локальные writeup, исходники скриптов и архивы. Не запускай `sudo pip install` для системного Python.

## Маршрут подготовки

Для короткого повтора иди так: `1H_CRASH_COURSE.md` → `5H_TRAINING_PLAN.md` → соответствующие темы `TRAIN_MANUAL.md` → шпаргалка из `07_CHEATSHEETS/` → подходящий скрипт из `scripts/` → локальные ICO writeup/ICO 2025 задачи → самостоятельное задание из `06_MINI_CTF/`. Не открывай `writeup.md` mini-CTF до собственной попытки.

В мини-CTF собраны 12 локальных задач, включая два Pwn-бинарника для Linux x86-64 и веб-задачу с loopback-only сервером. Все категории и точные команды запуска указаны в `06_MINI_CTF/README.md`. Каталоги `09_VIDEOS/` и `08_BOOKS/` содержат навигационные README; реальные видео там пока не сохранены.
