# 02. Работа с файлами и папками

## Что это такое?

Файлы хранят данные, а папки помогают их упорядочить. `cp` копирует, `mkdir` создаёт папку, `mv` перемещает.

# 05. file, strings, xxd, od и hexdump

## Что это такое?

`file` определяет тип, `strings` ищет печатные строки, а `xxd`, `od` и `hexdump` показывают байты.

file scripts/elf_triage.py
