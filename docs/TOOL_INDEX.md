# Справочник по инструментам

Состояние проверено в текущей системе. Команды `gobuster`, `yara`, `zsteg` и `ghidra` появляются в PATH после `source scripts/local_tools_env.sh`; это локальные инструменты проекта, а не отсутствующие программы. `volatility3` в PATH нет.

## Как загрузить инструменты проекта

```bash
source scripts/local_tools_env.sh
command -v gobuster
command -v yara
command -v zsteg
command -v ghidra
```

## `file`

- **Категория:** Работа с файлами
- **Установлен ли:** Установлен
- **Версия:** 5.47
- **Расположение:** `/usr/bin/file`
- **Что делает:** Определяет вероятный формат файла по содержимому.
- **Когда использовать:** Начинай с него почти для любого неизвестного вложения.
- **Первая команда:** `file FILE`
- **Основные команды:** `file FILE; file -b FILE`
- **Вход:** Путь к файлу.
- **Выход:** Название типа/формата.
- **Типичная ситуация в CTF:** Начинай с него почти для любого неизвестного вложения.
- **Частая ошибка:** Расширение имени может не совпадать с содержимым.
- **Работа без Интернета:** Работает без сети.
- **Связанные скрипты:** `scripts/forensics/01_file_type.sh`
- **Связанные задачи ICO:** Первичный анализ любых задач.

## `strings`

- **Типичная ситуация в CTF:** Быстрый поиск сообщений/подсказок в бинарнике.
- **Частая ошибка:** Строки не раскрывают всю логику программы.
- **Работа без Интернета:** Работает без сети.
- **Связанные скрипты:** `scripts/forensics/03_strings.sh`, `scripts/reverse/05_strings.sh`

## Дополнительные команды из проверенного списка

Следующие короткие записи дополняют справочник. Где команда отсутствует, указана доступная замена или реальный локальный источник; запуск в этом случае не изображается как проверенный.

### `od`

- **Что делает / когда применять:** показывает байты и числа в разных представлениях; используй для заголовков и двоичных данных.
- **Минимальная команда:** `od -An -tx1 -N32 FILE`
- **Следующий шаг:** сопоставь первые байты с ожидаемой сигнатурой; сверяй тип через `file`.
- **Типичная ошибка:** забыть, что смещение и формат вывода задаются ключами `-j` и `-t`.
- **ICO:** первичная проверка вложений; доступна офлайн.

### `hexdump`

- **Что делает / когда применять:** привычный шестнадцатеричный просмотрщик байтов; используется для заголовков.
- **Минимальная команда:** команда отсутствует в PATH; используй `xxd -g 1 -l 32 FILE` или `od -An -tx1 -N32 FILE`.
- **Следующий шаг:** проверь сигнатуру `file` и соответствующего формата.
- **Типичная ошибка:** считать отсутствие `hexdump` признаком отсутствия hex-инструментов.
- **ICO:** первичная форензика; замены доступны офлайн.

### Текстовые утилиты: `sed`, `awk`, `cut`, `sort`, `uniq`, `tr`

- **Что делают / когда применять:** выбирают строки и поля, преобразуют текст и подсчитывают повторы; полезны для логов, списков доменов и результатов сканирования.
- **Минимальная команда:** `cut -d, -f1 FILE | sort | uniq -c`; для замены символов — `tr 'A-Z' 'a-z' < FILE`.
- **Следующий шаг:** верни исходную строку для проверки контекста через `grep -n` или `rg -n`.
- **Типичная ошибка:** неверно выбрать разделитель либо отсортировать данные, порядок которых значим.
- **ICO:** обработка DNS/HTTP-логов и локальных подсказок; доступны офлайн.

### Кодирование и криптография: `base64`, `openssl`, `md5sum`

- **Что делают / когда применять:** Base64 кодирует байты, OpenSSL предоставляет криптографические операции, MD5 считает контрольный хеш для распознавания/сверки.
- **Минимальная команда:** `printf 'текст' | base64`; `printf 'текст' | openssl dgst -sha256`; `md5sum FILE`.
- **Следующий шаг:** установи, дано ли кодирование, хеширование или шифрование, затем выбери соответствующий раздел manual.
- **Типичная ошибка:** считать Base64 шифром или использовать MD5 как надёжный современный криптографический хеш.
- **ICO:** темы криптографии и проверка неизменности; команды доступны офлайн.

### `nm`

- **Что делает / когда применять:** перечисляет символы объектного файла/ELF и помогает найти имена функций.
- **Минимальная команда:** `nm -an BINARY | head`
- **Следующий шаг:** сопоставь символы с `readelf -s` и дизассемблированием.
- **Типичная ошибка:** ожидать имена из удалённой таблицы символов.
- **ICO:** reverse engineering ELF; доступен офлайн.

### `scapy` (Python)

- **Что делает / когда применять:** библиотека Python для чтения/создания пакетов и сетевого анализа.
- **Минимальная команда:** `.venv/bin/python -c 'from scapy.all import rdpcap; print(len(rdpcap("CAPTURE")))'`.
- **Следующий шаг:** выбери интересующий протокол/пакет и проверь вывод через `tshark`.
- **Типичная ошибка:** запускать системный Python вместо `.venv` или указывать несуществующий захват.
- **ICO:** сетевые и PCAP-задачи; библиотека импортируется в проектном окружении.

### Форензика медиа: `foremost`, `steghide`

- **Что делают / когда применять:** `foremost` ищет встроенные файлы по сигнатурам; `steghide` извлекает данные из поддерживаемых медиа при наличии пароля.
- **Минимальная команда:** `foremost -i FILE -o OUTDIR`; `steghide info IMAGE`.
- **Следующий шаг:** изучи извлечённые файлы отдельно через `file`, хеш и строки.
- **Типичная ошибка:** ожидать восстановления всех форматов или угадывать пароль вместо анализа подсказок.
- **ICO:** стеганография и форензика; команды доступны офлайн.

### `john` и `hashcat`

- **Что делают / когда применять:** проверяют гипотезы о пароле к локальному хешу/файлу с известным форматом.
- **Минимальная команда:** `john --wordlist=wordlists/common.txt HASHFILE`; `hashcat -m MODE HASHFILE wordlists/common.txt` (выбери корректный `MODE`).
- **Следующий шаг:** проверь формат хеша и небольшую подходящую локальную словарную выборку.
- **Типичная ошибка:** неправильный режим или ожидание результата на произвольной строке; учитывай время и оборудование.
- **ICO:** офлайн-задачи с паролями; используй только разрешённые артефакты.

### `ffuf`

- **Что делает / когда применять:** перечисляет веб-пути или параметры в рамках разрешённой цели.
- **Минимальная команда:** `ffuf -u http://AUTHORIZED_TARGET/FUZZ -w wordlists/raft-small-words.txt`
- **Следующий шаг:** сравни статус, размер и содержимое ответов; проверь найденный путь вручную.
- **Типичная ошибка:** забыть заменить `AUTHORIZED_TARGET` выданной целью или запускать перебор вне области соревнования.
- **ICO:** веб-задачи; сама программа доступна локально, цель/сеть могут требовать Интернет.

### `jq`

- **Что делает / когда применять:** извлекает поля из JSON-ответов и логов.
- **Минимальная команда:** `jq '.' FILE.json`
- **Следующий шаг:** сузь вывод фильтром, например `jq '.items[] | .name' FILE.json`.
- **Типичная ошибка:** передать невалидный JSON или неверный путь поля.
- **ICO:** обработка JSON/API в веб-задачах; доступен в локальном PATH проекта.

### `volatility3`

- **Что делает / когда применять:** анализирует дампы памяти.
- **Минимальная команда:** `scripts/vol.py -h`; безопасный локальный плагин: `scripts/vol.py frameworkinfo.FrameworkInfo`.
- **Следующий шаг:** для дампа запускай `scripts/vol.py -f MEMORY PLUGIN`; смотри `scripts/vol.py PLUGIN -h`.
- **Типичная ошибка:** считать репозиторий установленной и настроенной утилитой.
- **ICO:** форензика памяти; дампа для анализа в проекте нет, поэтому проверены только CLI и плагин без входного образа.

## Дополнительные сетевые и системные инструменты

Состояние проверено в текущем окружении после `source scripts/local_tools_env.sh` и активации `.venv`. Сетевые примеры ниже предназначены только для локальных лабораторий и явно разрешённых целей.

### `nmap`

- **Статус / назначение:** установлен; определяет открытые порты и сервисы.
- **Минимальная команда:** `nmap -sV -oN scan.txt AUTHORIZED_HOST`
- **Когда / следующий шаг:** перечисление разрешённого хоста, затем точечная проверка найденного сервиса.
- **Типичная ошибка:** запуск за пределами scope или слишком широкое сканирование.
- **ICO:** веб-сервисы и сетевая поверхность выданной задачи; требует доступной цели.

### `masscan`

- **Статус:** отсутствует; высокоскоростной сканер здесь не нужен. Локальная альтернатива — `nmap` с узким `-p PORTS`.
- **Пример при наличии:** `masscan AUTHORIZED_CIDR -p PORTS --rate 100` — только при прямом разрешении и низком согласованном rate.
- **Установка:** интернет/пакет Kali; локальной копии/архива в проекте не обнаружено.
- **ICO:** для локальных артефактов не нужен; офлайн-замена для PCAP — `tshark`.

### `ncat`

- **Статус:** команда `ncat` отсутствует; `nc` и `socat` доступны.
- **Пример / замена:** `nc -lv 127.0.0.1 4444` (синтаксис флагов зависит от реализации); для пары потоков смотри `socat -h`.
- **Когда применять:** ручная проверка собственного TCP-сервиса или локальной задачи.
- **Типичная ошибка:** открывать listener на всех интерфейсах или подключаться вне разрешённой цели.
- **ICO:** проверка выданного сетевого сервиса; `nc`/`socat` работают локально.

### `feroxbuster`

- **Статус:** отсутствует; доступные альтернативы — `gobuster` и `ffuf`.
- **Пример при наличии:** `feroxbuster -u http://AUTHORIZED_TARGET/ -w WORDLIST`.
- **Установка:** пакет/официальный релиз при наличии Интернета; локальной копии в проекте не найдено.
- **Когда / ошибка:** directory enumeration только по разрешённой цели; wildcard 404 и скорость дают ложный шум.
- **ICO:** веб-задачи; имеющиеся словари лежат в `wordlists/`.

### `gef` и `pwndbg`

- **Статус:** не установлены; команда `gdb` доступна. Это необязательные интерфейсные расширения GDB.
- **Замена:** `gdb -q ./chall`, затем `layout regs`, `info registers`, `x/16gx $rsp`, `bt`.
- **Установка:** отдельный официальный проект при наличии Интернета; локальных checkout/установщика не найдено.
- **Когда / типичная ошибка:** применяй расширение только если оно реально загрузилось в `gdb`; не путай его команды с GDB base.
- **ICO:** отладка локальных Pwn/reverse бинарников; GDB достаточен для базовых шагов.

### `ldd`

- **Статус / назначение:** установлен; показывает динамические зависимости ELF.
- **Минимальная команда:** `ldd ./BINARY`.
- **Следующий шаг:** сверить с `readelf -d BINARY` и проверить архитектуру через `file`.
- **Типичная ошибка:** не запускай `ldd` на неизвестном недоверенном ELF; некоторые реализации могут исполнить код загрузчика.
- **ICO:** исследование собственного/соревновательного бинарника; для безопасного статического просмотра используй `readelf`.

### `patchelf`

- **Статус / назначение:** установлен; читает/изменяет ELF interpreter, RPATH и SONAME.
- **Минимальная команда:** `patchelf --print-needed ./BINARY`.
- **Когда / следующий шаг:** для учебной локальной задачи сверяй библиотечные зависимости; изменение делай только на копии.
- **Типичная ошибка:** изменённый ELF отличается от исходного артефакта и может сломать эксперимент.
- **ICO:** отладка совместимости локального Pwn-бинарника; офлайн-доступен.

### `ROPgadget` и `ropper`

- **Статус:** `ROPgadget` доступен в `.venv`; `ropper` отсутствует. Локальная замена — `ROPgadget` и `objdump`.
- **Минимальная команда:** `.venv/bin/ROPgadget --binary ./BINARY --only "pop|ret"`.
- **Следующий шаг:** проверь найденный gadget в дизассемблере и учитывай PIE/ASLR/архитектуру.
- **Типичная ошибка:** список gadget не является готовым эксплойтом; адреса зависят от бинарника и runtime.
- **ICO:** локальные Pwn-задачи; сетевой доступ не нужен.

### `radare2` / `r2`

- **Статус / назначение:** установлены; консольный статический анализ бинарников.
- **Минимальная команда:** `r2 -A ./BINARY`, затем `afl`, `izz`, `pdf @ main`.
- **Следующий шаг:** перепроверь вывод в `objdump`, GDB или Ghidra.
- **Типичная ошибка:** автоанализ может неверно определить границы функции; не доверяй одному декомпилятору.
- **ICO:** дополнительный reverse-инструмент; доступен офлайн.

### `socat`

- **Статус / назначение:** установлен; соединяет локальные потоки и сокеты.
- **Минимальная команда:** `socat - TCP:AUTHORIZED_HOST:PORT` только для разрешённого сервиса; справка: `socat -h`.
- **Следующий шаг:** фиксируй вход/ответ и закрывай локальный listener после упражнения.
- **Типичная ошибка:** listener по умолчанию может стать доступен извне; привязывай к loopback в локальной практике.
- **ICO:** ручное взаимодействие с выданной TCP-задачей; наличие внешней цели требует сети.

### `xargs`

- **Статус / назначение:** установлен; превращает строки входа в аргументы команды.
- **Минимальная команда:** `find . -type f -print0 | xargs -0 -n1 file`.
- **Полезные варианты:** `-0` для NUL-разделителей; `-n1` по одному пути; `-r` не запускать на пустом вводе там, где поддерживается.
- **Типичная ошибка:** обычный пробельный ввод ломает имена с пробелами/переводами строки; используй `-print0` и `-0` вместе.
- **Следующий шаг / ICO:** применяй для массовой triage файлов, затем анализируй интересные результаты вручную; работает офлайн.

## Отдельные секции утилит для поиска и обработки текста

### `sed`

- **Статус / назначение:** установлен; печатает выбранные строки и делает потоковые замены.
- **Минимальная команда:** `sed -n '10,30p' FILE`.
- **Когда / дальше:** просмотри нужный диапазон, затем открой полный контекст совпадения.
- **Ошибка:** без `-n` sed обычно печатает все строки; `-i` изменяет файл.
- **ICO:** чтение локальных логов и исходников; офлайн.

### `awk`

- **Статус / назначение:** установлен; разбирает строки и поля.
- **Минимальная команда:** `awk -F, '{print $1}' FILE.csv`.
- **Когда / дальше:** выдели поле, затем свяжи результат с исходной строкой.
- **Ошибка:** разделитель и quoting должны соответствовать формату; пробелы в CSV требуют CSV-парсера.
- **ICO:** сортировка табличных логов и результатов сканирования.

### `cut`, `sort`, `uniq`, `tr`

- **Статус / назначение:** все четыре команды установлены; обрезают поля, сортируют, группируют дубликаты и заменяют символы.
- **Минимальные команды:** `cut -d: -f1 FILE`; `sort FILE | uniq -c`; `tr 'A-Z' 'a-z' < FILE`.
- **Когда / дальше:** нормализуй данные и проверь несколько исходных строк.
- **Ошибка:** `uniq` требует одинаковые строки рядом, обычно после `sort`; сортировка меняет порядок.
- **ICO:** обработка локальных списков/логов; офлайн.

## Отдельные секции кодирования и хешей

### `base64`

- **Статус / назначение:** системная команда установлена; кодирует/декодирует байты в текстовое представление.
- **Минимальная команда:** `printf 'ICO' | base64`; декодирование: `printf 'SUN' | base64 -d`.
- **Когда / дальше:** используй после распознавания алфавита; проверь обратный round-trip.
- **Ошибка:** Base64 не является шифрованием; не теряй бинарные нулевые байты.
- **ICO:** темы encoding и логи; офлайн.

### `openssl`

- **Статус / назначение:** установлен; криптографические дайджесты, кодировки и TLS-утилиты.
- **Минимальная команда:** `openssl dgst -sha256 FILE`; hex-строка: `printf 'text' | openssl enc -base64`.
- **Когда / дальше:** используй точную подкоманду из формата задачи и сравни с `sha256sum`.
- **Ошибка:** `enc` сам по себе не указывает надёжную схему/параметры; не путай digest с decrypt.
- **ICO:** проверка хешей и базовые crypto-упражнения; офлайн.

### `md5sum`

- **Статус / назначение:** установлен; legacy digest/checksum.
- **Минимальная команда:** `md5sum FILE`.
- **Когда / дальше:** идентификация формата/сверка с известным значением; для современного контроля используй SHA-256.
- **Ошибка:** MD5 не подходит для защиты целостности от намеренной подмены и не «расшифровывается».
- **ICO:** только если условие явно требует MD5; офлайн.

### `nm`

- **Статус / назначение:** GNU binutils установлен; перечисляет символы ELF/object.
- **Минимальная команда:** `nm -an BINARY | head -50`.
- **Когда / дальше:** найди символы функций/глобальных переменных и подтверди адрес через `objdump`.
- **Ошибка:** stripping удаляет имена; адреса PIE меняются при загрузке.
- **ICO:** reverse/Pwn triage локальных бинарников; офлайн.

- **Ошибка:** случайный `UPDATE`/`DELETE` меняет evidence; SQL-запросы и quoting shell требуют отдельных кавычек.
- **ICO:** локальные web/forensics базы; офлайн.

### `Docker`

- **Статус:** команда `docker` отсутствует; локальные задания из репозиториев могут включать Docker-конфигурации, но сами контейнеры здесь не запускаются.
- **Замена:** разбирай `Dockerfile`/`docker-compose.yml`, используй приложенные исходники и локальные бинарники.
- **Установка:** требует доступного пакета/daemon и дополнительных образов; offline-установка/образы не подтверждены.
- **Типичная ошибка:** наличие YAML не означает, что образ собран или загружен.
- **ICO:** не считай удалённые контейнерные сервисы офлайн-доступными.

### `nmap`, массовое сканирование и область задач

- **Практика:** сначала зафиксируй адрес из официального условия; используй один порт/хост, узкую проверку и выходной файл. Не сканируй инфраструктуру соревнования, если правила прямо этого не разрешают.
- **Локальный вход:** для уже сохранённого трафика активное сканирование не нужно — используй `tshark -r CAPTURE`.
- **Связь с ICO:** применяй только к сервису, явно выданному как часть задачи.
