# Видеотека подготовки к ICO

В каталоге пока нет локальных видео. Список курируемых ссылок находится в [`docs/VIDEO_INDEX.md`](../docs/VIDEO_INDEX.md); каждый ролик там отмечен `ONLINE ONLY`. Не включай видеосервис в план поездки без проверки, что конкретный материал разрешено сохранить официальной функцией и он действительно доступен офлайн.

## Russian

В `VIDEO_INDEX.md` выше английских запасных материалов перечислены русскоязычные вводные по Linux, форензике и Pwn. Озвучка указана по языку ролика; наличие субтитров отмечено только если проверено.

## English

Англоязычные материалы оставлены как запас, если русское видео по теме не найдено. Основные объяснения темы есть в русскоязычном `docs/TRAIN_MANUAL.md`.
