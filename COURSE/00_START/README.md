# Начни здесь

Открой этот файл из корня проекта. Он ведёт по существующему курсу, не копируя исходные уроки.

## Шаг 1 — обзор курса

Прочитай [START_HERE](../../docs/START_HERE.md), затем открой [план на 5–6 часов](../../docs/5H_TRAINING_PLAN.md). Если нужно быстро освежить команды — пройди [часовой crash course](../../docs/1H_CRASH_COURSE.md).

## Шаг 2 — подготовь рабочую среду

Из корня проекта проверь окружение и инструменты:

```bash
cd /home/zuck/ico2027
source scripts/local_tools_env.sh
source .venv/bin/activate
python --version
```

Затем следуй [Linux блоку](../01_LINUX/README.md): темы терминала, файлов, поиска, форматов и хешей (темы 01–08 TRAIN_MANUAL). Выполняй практики, перечисленные в самих темах; отдельные новые упражнения здесь не вводятся.

## Шаг 3 — выбери темп

- Полный путь по плану: [5–6 часов](../../docs/5H_TRAINING_PLAN.md).
- Быстрое повторение: [1 час](../../docs/1H_CRASH_COURSE.md).
- Последовательно изучать материал: [68 тем TRAIN_MANUAL](../../docs/TRAIN_MANUAL.md) и [чеклист прогресса](../PROGRESS.md).

## Шаг 4 — отрабатывай по категориям

Иди от Linux к Reverse и Pwn, затем выбери Forensics, Network, Crypto, Web, Stego и OSINT. Каждая страница категории связывает реальные уроки, шпаргалки, scripts, локальные mini-CTF и имеющиеся ICO материалы.

## Шаг 5 — решай локальные задания

[Mini-CTF](../../06_MINI_CTF/README.md) содержит 12 задач с условиями и writeup. Сначала открой условие, реши самостоятельно, затем переходи к writeup. После этого используй локальные [ICO 2025 задачи](../../05_REPOS/ico-tasks/README.md) и [ICO 2027 материалы](../../ico-2027/README.md), учитывая их фактический состав.

## Если застрял

Открой [WHEN_STUCK](../WHEN_STUCK.md), [тему 66 руководства](../../docs/TRAIN_MANUAL.md#66-что-делать-если-застрял) или [справочник инструментов](../../docs/TOOL_INDEX.md). Для конкретной задачи сверяйся с её writeup после собственной попытки.
